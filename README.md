# Vite & Gourmand

Application web de présentation et de commande de menus pour l'entreprise Vite & Gourmand.

## Objectif

Permettre aux visiteurs de consulter les menus, créer un compte, commander un menu et suivre leurs commandes.
Permettre aux employés de gérer les menus, commandes et avis.
Permettre à l'administrateur de gérer les employés et consulter les statistiques.

## Stack technique envisagée

- Front-end : HTML5, CSS3, Bootstrap, JavaScript
- Back-end : PHP avec PDO
- Base relationnelle : PostgreSQL ou MySQL
- Base NoSQL : MongoDB
- Déploiement : Fly.io / Heroku / Vercel selon choix final

## Installation locale

1. Cloner le dépôt
2. Importer le fichier SQL présent dans `database/sql`
3. Configurer les variables d'environnement
4. Lancer le serveur local PHP
5. Accéder à l'application depuis le navigateur

## Branches Git

- `main` : version stable
- `develop` : version de développement
- `feature/...` : branches par fonctionnalité
