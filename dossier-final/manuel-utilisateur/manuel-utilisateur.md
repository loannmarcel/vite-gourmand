# Manuel utilisateur - Vite & Gourmand

## Présentation de l'application

Vite & Gourmand permet de consulter des menus, créer un compte, passer commande et suivre ses commandes.

## Parcours visiteur

1. Accéder à la page d'accueil
2. Consulter les menus
3. Filtrer les menus
4. Voir le détail d'un menu
5. Créer un compte ou se connecter

## Parcours utilisateur

1. Se connecter
2. Choisir un menu
3. Commander
4. Consulter le suivi de commande
5. Laisser un avis après commande terminée

## Parcours employé

1. Se connecter
2. Gérer les menus
3. Gérer les commandes
4. Modifier les statuts
5. Valider ou refuser les avis

## Parcours administrateur

1. Se connecter
2. Créer un employé
3. Désactiver un employé
4. Consulter les statistiques
