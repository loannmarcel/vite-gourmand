# Documentation technique - Vite & Gourmand

## 1. Présentation du projet

Présentation rapide de l'application et de son objectif.

## 2. Choix technologiques

Expliquer et justifier :
- Front-end
- Back-end
- Base relationnelle
- Base NoSQL
- Déploiement

## 3. Environnement de travail

Lister :
- Éditeur de code
- Version PHP
- Base de données
- Outils utilisés
- GitHub
- Outil de gestion de projet

## 4. Modélisation

Inclure :
- MCD ou diagramme de classe
- Diagramme de cas d'utilisation
- Diagramme de séquence

## 5. Sécurité

Expliquer :
- mots de passe ;
- injections SQL ;
- XSS ;
- gestion des rôles ;
- sessions ;
- RGPD.

## 6. Déploiement

Expliquer toutes les étapes :
- préparation du projet ;
- configuration de la base ;
- variables d'environnement ;
- mise en ligne ;
- tests après déploiement.

## 7. Conclusion technique

Bilan, limites et améliorations possibles.
