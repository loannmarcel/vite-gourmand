# Documentation de gestion de projet

## Outil utilisé

Outil choisi : Trello / Notion / Jira

Lien vers l'outil :

## Méthode utilisée

Le projet est organisé sous forme de tâches regroupées par étapes :
- Analyse
- Maquettage
- Front-end
- Back-end
- Base de données
- Sécurité
- Déploiement
- Documentation

## Organisation des tâches

Chaque tâche possède :
- un titre ;
- une description ;
- une priorité ;
- un statut ;
- éventuellement une date limite.

## Statuts utilisés

- À faire
- En cours
- À tester
- Terminé

## Justification

Cette méthode permet de suivre l'avancement du projet, de prioriser les fonctionnalités importantes et de conserver une trace de la démarche projet.
