# Réflexions initiales et choix techniques

## Front-end

Technologies envisagées :
- HTML5
- CSS3
- Bootstrap
- JavaScript

Justification :
Ces technologies permettent de créer une interface responsive, accessible et dynamique sans complexité excessive.

## Back-end

Technologie envisagée :
- PHP avec PDO

Justification :
PHP avec PDO permet de développer des composants côté serveur et de communiquer avec une base de données relationnelle en limitant les risques d'injection SQL grâce aux requêtes préparées.

## Base relationnelle

Technologie envisagée :
- PostgreSQL ou MySQL

Justification :
Une base relationnelle est adaptée pour gérer les utilisateurs, menus, plats, commandes, avis et relations entre entités.

## Base NoSQL

Technologie envisagée :
- MongoDB

Justification :
MongoDB sera utilisé pour stocker des données statistiques ou analytiques, comme le nombre de commandes par menu.

## Déploiement

Solutions envisagées :
- Fly.io
- Heroku
- Vercel

Choix final à justifier après tests.
